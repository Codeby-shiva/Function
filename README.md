# Function

This  is a function that convert input marks out of 600 to percentage %

# How to use it
-> Put the marks between (0, 600) .
-> And it will show your the correct percentage % out of 100% .
-> You can put marks 600 times here between (0,600) , this loop will be stop or break  when you put invalid, or out of range in input.
-> So, please use correctly and enjoy this function.
